So, we will be using SqlServer+Dapper for POS.

Our POS database must handle :
1. Customer
2. Products and Categories.
3. Order and Order details.
4. Billing
5. Inventory
6. Payments
7. Sales Report

So A basic retrieve sales will be something like :

FrontEnd (Angular) sales Page -- > POS API controller -->ISales Interface --> Sales Repository -->
Dapper --> SQL server SP(Stored Procedure) -- > Sales Result

Inventory:
We are using PostGRESQL + EF(Entity Framework)Core 

Inventory database must handle:
1. Stock balances.
2. Inventory Movements.
3. Stock Receipts
4. Stock Adjustments
5. Supplier and Purchase Records.
